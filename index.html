Pronto para baixar um link direto autorizado.

Abrir link direto
Este protótipo aceita arquivos diretos servidos com acesso permitido pelo próprio site. Não baixa de contas, plataformas protegidas, DRM ou links que exijam contornar restrições.

Limite do navegador: alguns sites não permitem que esta página leia o arquivo (CORS) ou não oferecem o vídeo como arquivo direto. Nesses casos, use “Abrir link direto”; o site pode exibir o vídeo em vez de baixá-lo. O protótipo não envia o link a nenhum servidor.
